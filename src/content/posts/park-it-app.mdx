## What's this about

If you've ever driven in Singapore, you know the pain. Google Maps will happily route you to a mall but won't tell you if there's actually parking available, what it costs, or whether there's EV charging. As a new driver I found this incredibly stressful, so I built something to fix it.

Repo: [github.com/JeremyQuek/Park-It-app](https://github.com/JeremyQuek/Park-It-app)

Live: [park-it-maps.vercel.app](https://park-it-maps.vercel.app/)

---

## What it does

It's a web app that shows you live parking data across Singapore: available lots, lot types, EV charging spots, locations, and prices. All sourced from LTA and HDB open data endpoints, updated every minute.

### The Intended flow

The image on the right shows the home page of the application. It brings users to a google style like maps created using Mapbox

When users input a destination, the app calculates the route and plots a route, but it also brings up a list of 10 of the nearest carparks.
This comes with information such as price and lot availability where its available

## How it works

React frontend, Python Flask backend, Supabase Postgres for persistence. A cron job hits the LTA/HDB APIs every minute and caches the data. I also threw in a Groq LLM integration to parse the unstructured pricing formats (they're a mess across different carparks).

## Services

1. **Frontend (Vercel)** — React app with global edge delivery
2. **Backend (Render)** — Flask server handling carpark logic
3. **Database (Supabase)** — Postgres for bookmarks and carpark data
4. **LLM (GroqCloud)** — Dynamically parses unstructured price formats
5. **Cron (Cron-Job.org)** — Triggers `/update` every minute to refresh data

---

## What I'd do differently

Honestly the DB was overkill for this. The number of carpark lots in Singapore is bounded, so the whole thing could live in memory with Redis alongside the backend. Would be way faster for lookups. The Postgres setup was from initial project requirements but if I rebuilt it today, Redis + in-memory tree is the move.
