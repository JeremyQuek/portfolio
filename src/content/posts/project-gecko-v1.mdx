## What's this about

I tried to create a basic type checker in Python ([here](/posts/type-checker-python)), and realised how hard it was. 
But because the topic really interested me, I decided to scope out a proper basic structure for an MVP tool which 
could type check python and cover the gaps (mainly type provenance) of modern tools like MyPy/Pyright etc...

Repo: [github.com/JeremyQuek/gecko](https://github.com/JeremyQuek/gecko)
